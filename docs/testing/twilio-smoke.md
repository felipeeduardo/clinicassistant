# Twilio Sandbox smoke

O fluxo é manual e exige `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_WHATSAPP_FROM` e `NGROK_AUTHTOKEN`. Execute `./scripts/local/start-twilio-smoke.sh`; a URL temporária fica somente em `.tmp/ngrok-url`. Nenhuma mensagem é enviada automaticamente e o Console Twilio não é alterado.
