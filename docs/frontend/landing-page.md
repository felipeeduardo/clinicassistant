# Landing Page comercial

A rota pública `/` apresenta a proposta real do Clinic Assistant sem autenticação e sem dados de pacientes. Inclui hero, demo visual do WhatsApp, problema, pilares WhatsApp/Agenda/Gestão, diagrama operacional, recursos, segurança, FAQ, CTA de demonstração e link de entrada.

O CTA de demonstração usa e-mail configurável como placeholder até existir backend de leads com validação, rate limiting e anti-spam. Não há promessa de IA, certificação ou indicadores quantitativos.
