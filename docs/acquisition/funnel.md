# Funil comercial e operação

## Etapas

`Visitor → CTA → Form → New → Contacted → DemoScheduled → DemoCompleted → Pilot → Won`.

`Lost` encerra uma oportunidade sem apagar o histórico; `Archived` é apenas organização. `Qualified` permanece aceito para compatibilidade com registros antigos.

## Trabalho diário

1. Acesse **PlatformAdmin → Leads comerciais**.
2. Filtre por status, origem UTM, período ou responsável e pesquise nome, clínica, e-mail ou telefone.
3. Abra o lead para conferir atribuição, descrição, histórico e último contato.
4. Atualize o status após cada contato e registre a próxima ação com data e descrição.
5. Use **DemoScheduled**, **DemoCompleted**, **Pilot** e **Won** somente quando houver evidência operacional.

O dashboard mostra apenas contagens persistidas de leads, demonstrações, pilotos e clientes. Não há MRR, CAC ou conversão estimados sem dados financeiros reais.
